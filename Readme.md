Cada pasta nomeada como `Desafio + número` contém o respectivo desafio. Dentro de cada uma delas há um `readme.md` com as instruções para execução, além de uma breve explicação sobre a abordagem utilizada e as decisões tomadas durante o desenvolvimento

Na pasta `Desafios` estão disponíveis os enunciados utilizados como referência para a realização dos desafios

Na pasta `Uso De IA` está disponível a resposta referente à utilização de ferramentas de Inteligência Artificial durante o processo de desenvolvimento, conforme solicitado no desafio técnico
